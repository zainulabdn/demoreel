Demoreel GitHub

Your coding agent records the demo video

Ask Claude Code or Codex for a demo of your app. Demoreel drives your real app in a headless browser and renders a polished video: smooth cursor, zoom on every action, captions, and a voice-over when you want one. MP4 and GIF, zero dependencies.

A storyboard is a list of steps in plain language. Elements are named the way a person sees them: the text on a button, the label on a field. The cursor paths, the typing rhythm and every camera move are worked out for you.

{
  "serve": ".",
  "displayUrl": "lumen.app",
  "style": { "background": "dusk" },
  "steps": [
    { "say": "Start a project in seconds" },
    { "click": "New project" },
    { "type": "Website launch", "into": "Project name" },
    { "click": "Create project" },

    { "say": "Add tasks as fast as you can type" },

Add one line, and it speaks

Every caption is spoken, clicks and key presses can be heard, and the recording waits for each sentence, so the voice and the picture stay together. Press play to hear it.

The same app, recorded with "sound": { "voice": true } in the storyboard. The voice is a free model that runs on your own machine.

What you get

One request to your agent, four files next to your storyboard.

Your real app

It opens the app you built and uses it with real mouse and keyboard input. No mockups, no redrawn screens.

A camera that follows

It zooms in as the cursor arrives, holds while you type, and follows what changed: the dialog, the new row, the toast.

Every shape you post in

1080p for READMEs and X, square for LinkedIn, vertical for Reels. Browser, window or phone frame.

It checks its own work

A contact sheet shows one frame per step, so the agent can look at the video it made and fix what is off.

A voice that keeps time

Captions are spoken by a natural voice, your computer's own, or clips you recorded. The video waits for every line.

Sound, already mixed

Click and typing sounds on the exact frame, music that steps back under the voice, and the loudness social sites expect.

Install

You need Node.js 20 or newer and Chrome, Edge or Brave. No Playwright, no ffmpeg, no npm install, no API key.

claude plugin install demoreel@demoreel
